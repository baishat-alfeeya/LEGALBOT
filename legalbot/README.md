# LEGALBOT - AI Legal Assistance

Next.js 14 + TypeScript + Tailwind CSS + Framer Motion

## Setup

1. Install Node.js from https://nodejs.org
2. Run: cd legalbot && npm install && npm run dev
3. Open http://localhost:3000

## Pages
- / Home
- /chat AI Chat with voice
- /lawyers Find lawyers + booking
- /documents Document analyzer
- /emergency Emergency guidance
- /rights Know your rights
- /tourist Tourist shield
- /templates Legal templates
- /location Nearby services
- /risk Risk detection
